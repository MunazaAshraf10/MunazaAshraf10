## World-to-Policy Distillation

Implemented **World-to-Policy Transfer via Online World Model Distillation** using a pretrained OccWorld model.

The system distils planning knowledge from a large world model into a lightweight autonomous-driving policy that can operate without the world model during deployment.

[View Project](https://github.com/MunazaAshraf10)
